# Laboratório de engenharia e automação

Projetos **demonstrativos e independentes**, criados com dados fictícios para ilustrar padrões técnicos. Não representam código, informações ou resultados de clientes.

| Projeto | Demonstra | Stack |
|---|---|---|
| [Resilient RPA](./resilient-rpa/) | retries, idempotência, logs, CLI e testes | Python |
| [ERP Integration API](./erp-integration-api/) | contrato REST, validação e integração simulada | Python, FastAPI |
| [Operational Analytics](./operational-analytics/) | modelagem SQL e métricas de operações | SQLite, SQL |

Executar cada exemplo localmente conforme o README do projeto. Nenhum exemplo requer credenciais, serviços externos ou acesso a ambientes corporativos.
